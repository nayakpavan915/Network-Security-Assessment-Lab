
# Network Security Assessment Lab

## Overview
A network security lab focused on firewall configuration,
network segmentation, vulnerability assessment, and
security remediation validation using pfSense.

## Objectives
- Understand firewall configuration and network security.
- Implement network segmentation between LAN, DMZ, and management zones.
- Review firewall rules and identify potential security weaknesses.
- Perform host discovery and port scanning using Nmap.
- Conduct vulnerability assessment on authorized lab systems.
- Document findings using risk ratings.
- Validate remediation through retesting.

## Lab Architecture
The lab is designed around a firewall-based network architecture
with logically separated network zones.

Planned network zones:
- LAN
- DMZ
- Management Network
- Isolated Testing Network

## Tools
- pfSense - Firewall and network segmentation
- Nmap - Host discovery and port scanning
- Nessus Essentials - Vulnerability assessment
- Kali Linux - Security testing environment
- Metasploit - Vulnerability validation in an authorized lab
- Burp Suite - Web application testing

## Assessment Workflow
1. Configure the virtual network.
2. Implement firewall rules.
3. Identify hosts and exposed services.
4. Conduct vulnerability assessment.
5. Analyze and prioritize security findings.
6. Prepare remediation recommendations.
7. Apply security fixes.
8. Perform retesting.
9. Document assessment results.

## Deliverables
- Network topology
- Firewall rule review
- Nmap scan results
- Vulnerability assessment report
- Risk register
- Remediation tracker
- Retesting evidence
